# 自我探索練習室

課堂互動測驗：私人自我意識、自戀特質、獨立自我與相依自我、16 型人格、大五人格與自尊。

各測驗可直接使用瀏覽器作答。FFNI 完整問卷的研究收件狀態顯示於該問卷頁首。

## FFNI 深入探索試用版

短版自戀測驗完成後，可自願進入 `ffni/` 的 148 題完整問卷，提供繁體中文待審閱試譯、英文原題對照、選填背景資料、進度接續、15 面向及組合分數、列印與個人資料下載。研究收件開啟時，參與者可於最後一頁送出答案與選填背景。聯絡信箱選填，另頁保存。收件設定見 `integrations/google-sheets/README.md`。

驗證計分：`node ffni/scoring.test.mjs`。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save。

各測驗的題目、計分規則與來源說明列於其頁面。教材摘錄版供教學探索使用，不作為診斷工具。
