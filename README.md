# 自我探索練習室

課堂互動測驗：私人自我意識、自戀特質、獨立自我與相依自我、16 型人格、大五人格與自尊。

純 HTML/CSS/JavaScript，不需安裝依賴，不收集作答資料。

## FFNI 深入探索試用版

短版自戀測驗完成後，可自願進入 `ffni/` 的 148 題完整問卷，提供繁體中文待審閱試譯、英文原題對照、選填背景資料、進度接續、15 面向及組合分數、列印與個人資料下載。電郵欄位為流程預覽，不會儲存或寄送。尚未啟用研究資料蒐集後端；詳細限制及正式上線前待辦見 `ffni/README.md`。

驗證計分：`node ffni/scoring.test.mjs`。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save。

各測驗的題目、計分規則與來源說明列於其頁面。教材摘錄版供教學探索使用，不作為診斷工具。
